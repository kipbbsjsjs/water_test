# water_test — ESP32 超声波水位检测台

毕业设计《基于 ESP32 的洗车工位喷淋控制系统》的超声波水位单元测试程序。
用于验证 HC-SR04 非接触水位检测与水量/费用换算逻辑。

## 功能

- 网页实时显示：测距值、当前水位、用水量（L）、模拟消费金额（元）
- 水槽可视化（液面动画）+ 24 秒水位波形（每格 250ms）+ 事件日志
- 中位数滤波（3 次采样取中值），剔除异常回波；25ms 超时保护
- 峰值记录（历史最高/最低水位）、采样/失败计数
- SSE 长连接推送，OLED 本地同步显示
- WiFi 断开自动重连，无网页客户端时采样不停止（峰值/日志不丢）

## 接线

| HC-SR04 | ESP32 |
|---------|-------|
| VCC | 5V（VIN） |
| Trig | GPIO25 |
| Echo | GPIO33（**必须经 1kΩ+2kΩ 电阻分压至 3.3V**，5V 直连会损坏芯片） |
| GND | GND |

OLED 0.96" I2C：VDD→3.3V、SDA→GPIO21、SCL→GPIO22。

## 使用

1. 代码内填入自己的 `WIFI_SSID` / `WIFI_PASS`（2.4GHz）
2. Arduino IDE（ESP32 板卡包 + U8g2 库）烧录
3. 串口 115200 查看 IP，手机同局域网浏览器打开

水槽深度 / 截面积 / 费率在代码顶部 `TANK_DEPTH_CM` / `TANK_AREA_CM2` / `YUAN_PER_L` 修改。
